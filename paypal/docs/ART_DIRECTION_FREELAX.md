# FreelaX Art Direction
Status: CANONICAL DESIGN DIRECTION
Implementation: DESIGN PREPARATION ONLY

## Canonical direction
**FreelaX — Kinetic Editorial Brutalism**

Internal system name: **FreelaX Graphic Work System**

Mix:
- 50% Editorial Kinetic
- 30% Neo-Brutalist Graphic Language
- 15% Financial / Institutional Discipline
- 5% Experimental Motion

## Core DNA
Use editorial composition, bold typography, flat saturated color, dark ink borders, restrained hard offset shadows, geometric blocks, intentional asymmetry, state-driven kinetic motion, ledger/statement discipline, strong dividers, and role + task + state + next-action hierarchy.

## Anti-SaaS / anti-Web3-template rules
Do NOT default to:
- bento dashboards
- card-for-everything
- glass / blur / glow
- atmospheric gradients
- large soft shadows
- excessive rounded corners
- status pills everywhere
- centered SaaS hero + CTA
- generic blue-gradient startup styling
- dark cyan/teal Web3 styling
- wallet-first navigation
- fake-fintech balance cards

## Composition grammar
Marketplace: editorial list, strong job title, metadata columns, dividers, deliberate asymmetry.
Workspace: workflow rail + current action ownership + submission history.
Submission review: document/review composition.
Payment: statement / settlement record.
Payout: lifecycle rail + evidence + estimated conversion.
Tax/certificate: calm document/evidence layout.
Activity: unified event stream.
Account/auth: structured forms with lower visual experimentation.

## Kinetic UI
Motion is state-driven, not decorative. It must answer at least one:
- What changed?
- What is active now?
- Who owns the next action?
- Did the action succeed?
- What happens next?

Primary kinetic targets: application, assignment, work submission, revision, approval, payment capture, payout progression, evidence/tax readiness.

Avoid continuous decoration, breathing glow, elastic bounce, large zoom, and excessive parallax. Respect reduced motion.

## Differentiation
From School Safety R&D keep graphic confidence, flat color, ink boundaries, hard shadows and disciplined motion; reduce playful campaign energy and increase professional/work/financial restraint.

From BlinkShop/common Solana products: FreelaX is work-first, editorial, job/submission/review-first, and evidence-aware. Solana is infrastructure/evidence, not visual identity.

## Product framing
Visual hierarchy reinforces:

WORK → REVIEW → APPROVAL → PAYMENT → PAYOUT → EVIDENCE

Not:

WALLET → TOKEN → NETWORK → TRANSACTION
