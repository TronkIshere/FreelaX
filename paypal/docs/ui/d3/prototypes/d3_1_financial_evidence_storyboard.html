What remains true if a stage fails

Work approval and checkout capture remain valid after a later on-ramp, payment, withdrawal, simulated payout, or tax failure. Name the failed stage and preserve the last confirmed evidence. Participant payout status has no generic retry operation.

Evidence is event-specific

On-ramp, rate, invoice, payment, withdrawal, and completion each have separate proof. Fixture identifiers above are deliberately non-live. A real backend-provided DEVNET Explorer URL belongs under its event, never as proof of bank settlement.
