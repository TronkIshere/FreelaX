# FreelaX Interactive Demo v0.1

Open [index.html](index.html) directly in a browser. No server or build step is needed.

Walkthrough: **FREELANCER** Khám phá → open the 500 USD job → Ứng tuyển; switch to **CLIENT** → Công việc → open job → Ứng tuyển → Chọn Freelancer; switch to **FREELANCER** → Workspace → submit V1; switch to **CLIENT** → request revision; switch to **FREELANCER** → submit V2; switch to **CLIENT** → approve → open financial evidence; switch to **FREELANCER** → Thu nhập → use **DEMO CONTROLS / Next financial event** through event 08 → open the tax record.

The role switch preserves the local demo state. **Reset demo** clears it and returns to Freelancer discovery.

Financial values and IDs are **design fixtures**. Payout is **MÔ PHỎNG** on **DEVNET**; VND is **estimated**, and no real bank transfer occurs.
